# LEONIDA NIGHTS

An open-world crime game in the spirit of GTA 6, built for the [make.fun gta6-01 bounty](https://make.fun/bounty/gta6-01). Explore the neon city of Leonida on foot and by car — steal cars, outrun the police, take on missions, and build your reputation.

## How to play

Serve the game locally with `node serve.ts`, then open http://localhost:8080 in a desktop browser.
